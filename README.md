# Taktik

A non-commercial web recreation of TakTik (Kickoo, 2002), a two-player turn-based board game originally released on Palm OS.

**Play it in your browser: https://jeromedusanter95.github.io/TakTik/**

The web build is tested and deployed to GitHub Pages on every push to `main` (see `.github/workflows/deploy-web.yml`).
